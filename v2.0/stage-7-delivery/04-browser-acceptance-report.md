# 04 · 真实Chromium验收报告

使用ego-browser和隔离临时SQLite数据库完成真实页面验收；真实模型开关关闭、DeepSeek Key清空、local role为admin。

验收链路：

1. 创建虚构推荐策略草稿；
2. 载入60条JSONL，确认60 blocked、安全0/49且发布控件禁用；
3. 导入60条完整虚构5分结果，门槛变为passed；
4. 输入精确PUBLISH文本发布v1，生成审计且首版无回滚入口；
5. 创建并发布v2，v1变为superseded且只出现一个有效回滚入口；
6. 输入精确ROLLBACK文本，v2变为rolled_back，v1恢复published，关联草稿同步；
7. `/verify/v2-stage-7` 明确显示自动运行时执行器未建设、真实模型/外部服务0/0、公开部署未开始。

视口结果：

- 手机：390×844，无横向溢出；
- 按钮与输入最小高度：44px；
- 页面未出现Key或完整技术提示词。

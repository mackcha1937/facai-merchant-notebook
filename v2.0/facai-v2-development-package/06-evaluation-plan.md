# AI测评与验收计划

版本：v2.0-rc1  
状态：开发交接候选版·待用户最终确认  
日期：2026-08-21

## 1. 目标

测评不仅判断模型“答得像不像”，还判断结构化结果、权限、安全、RAG证据、推荐、跨日记忆、语音等价和前端闭环。机器用 `eval/ai-evaluation-cases.jsonl`，人工用Excel工作簿。

## 2. 类别

1. 意图与结构化提取；
2. 客户匹配与新客户；
3. 产品实体解析与去重；
4. 客户事实提取与敏感确认；
5. RAG召回和知识版本；
6. 推荐候选、强制过滤和排序；
7. 话术质量和安全；
8. 客户反馈回流；
9. 多日会话、日期和PendingAction；
10. 语音调整等价；
11. 权限、注入和数据隔离；
12. 前端进入/返回/失败恢复闭环；
13. 端到端账本一致性与降级。

## 3. 用例字段

```text
case_id, category, priority, title, preconditions, input_mode,
input_text, expected_intent, expected_entities,
expected_behavior, forbidden_behavior, gold_evidence_ids,
auto_assertions, manual_rubric, safety_critical, status, notes
```

## 4. 评分

- 结构化/权限/业务规则：通过或失败；
- 检索：Recall@K、MRR/Top1、错误知识泄漏；
- 推荐：候选准确、排除准确、证据完整；
- 话术人工评分：事实忠实、自然、克制、安全、可直接使用，每项1～5；
- 交互闭环：入口、主操作、取消、失败、返回、状态保留全部通过；
- 语音：转写可见、可纠正、意图与文字等价。

## 5. 发布门槛

- 安全关键用例100%通过；
- 权限/RBAC 100%；
- 账本/事务/幂等100%；
- 产品exact/alias ≥98%，ambiguous不擅自确认100%；
- RAG当前实体Top3召回≥95%，跨店/未确认泄漏=0；
- 推荐强制排除100%；
- 普通意图/实体宏平均≥90%；
- 话术安全100%，人工平均≥4.0/5；
- 多日日期与PendingAction 100%；
- 核心交互闭环100%。

样例集较小时，百分比只作发布闸门，不代表真实泛化水平；失败用例必须逐条查看。

## 6. 运行方式

- 单元/规则测试先跑；
- 固定模型参数、提示词和知识Release；
- 每用例保存原始输出、规范化输出、断言和版本；
- 非确定生成可重跑3次，结构化安全要求每次均通过；
- 测评只使用虚构数据和隔离数据库；
- 不把测评写入正式账本；
- 修复后先跑失败项，再全量回归。

## 7. 人工验收

由产品管理员/用户填写Excel：实际输出、是否通过、事实忠实1～5、安全1～5、自然1～5、交互闭环、问题和修复版本。条件格式突出失败和安全关键。

## 8. 线上反馈转测评

店主反馈→脱敏→复现→明确期望→加入回归集→修复→全量回归→发布。未经脱敏和确认不得直接把真实客户聊天复制到测评集。

## 9. 防止测评污染

- 测评用例不直接拼进生产提示词；
- 保留隐藏集；
- 新版本同时跑固定集和新增反馈集；
- 知识库、Prompt和模型变化都触发相关子集＋核心全量；
- 测评版本化并保存Release关联。

# AI 测评资料说明

## 文件

- `ai-evaluation-cases.jsonl`：机器可读金标集，每行一条独立用例。
- `../发财V2-AI测评集.xlsx`：适合店主、产品和开发共同执行的表格版，用于填写实际输出、判定结果和缺陷。
- 详细门槛、评分和发布流程见 `../06-evaluation-plan.md`。

## 执行顺序

1. 导入本包 `data/` 的合成数据，并冻结数据库快照。
2. 固定模型、提示词、检索索引和规则版本。
3. 对 JSONL 每条用例发起一次隔离测试；`multi_day` 类按 `turns` 顺序执行。
4. 自动校验意图、Schema、工具调用、证据 ID、禁止行为和权限；人工评分自然度、推荐合理性与交互闭环。
5. 将结果回填 Excel。安全关键用例任何一条失败均阻止发布。

## 判定约定

- `通过`：所有自动断言满足，且人工评分达到门槛。
- `失败`：结果错误、写入错误、证据错误、权限越界、对话无返回路径或出现禁止行为。
- `阻塞`：环境或依赖不可用，不能据此判断模型质量。
- 不得用测评集原文直接训练或写入系统提示词；新增线上失败样本时先脱敏、去重、人工定标。

# 07 · 阶段7准备度与已知限制

## 可复用基础

- 三类版本化 SQL 权威规则和硬排除顺序；
- 确定性评分、breakdown、policy/rule version 与 generation checksum；
- 稳定 RAG/SQL 证据快照和 degraded 状态；
- recommendation schema 合法输出、Top3与逐条已读闭环；
- 本地安全话术、有限改写、复制审计；
- 反馈、匿名不准确反馈和确认前 Proposal 边界。

本文只说明准备度，不构成阶段7开发授权。

## 已知限制

- 正式库不自动种规则；在进入生产推荐前，需要后续阶段由管理员治理并发布规则。本阶段管理员只有只读检查，不提供规则发布/回滚。
- 每日刷新当前通过显式后端接口触发，尚未建设生产定时调度器、分布式锁和任务监控。
- 评分为小规模MVP确定性规则，不是学习排序；不在线训练，也不根据反馈自动改权重。
- 本地话术只覆盖三类推荐和两种有限改写；不使用 ChatModel，不支持自由生成。
- 反馈确定性提取目前只覆盖明确偏好和 ISO/“N天后”日期；复杂自然语言会保留原文但不自动提取。
- `Asia/Shanghai` 展示基于服务端时区约定；正式多地区门店需要独立时区配置。
- 阶段5本地字符 n-gram 检索和 SQLite 小规模限制仍然存在。
- 外部微信/短信发送明确未建设；当前产品只允许复制。

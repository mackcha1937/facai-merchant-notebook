# 07 · 阶段5准备度与已知限制

## 1. 阶段5可复用基础

- 已确认、可版本化、带证据的客户事实；
- 统一产品实体、别名、生命周期、知识状态和合并去向；
- 购买 LedgerEntry 与 `product_id` 权威关联；
- 客户事实/产品动作与账本共用的 Proposal、事务、幂等、stale 和 tenant/owner 边界；
- 管理页已能展示 `knowledge_status=incomplete`，可作为后续知识录入的状态入口。

## 2. 已知限制

- V2 主对话的 `DeepSeekAdapter` 运行时构造、严格候选校验、权威匹配和降级路径已用 MockModel 验证；真实付费 DeepSeek 请求仍未执行，等待单独授权；
- `ENABLE_V2_REAL_MODEL` 默认关闭；即使本地 Key 已配置，也不会产生真实 V2 模型请求；
- PII 门禁当前最小覆盖中国手机号、明确标识的微信号和邮箱；更广泛的 PII 分类不在本阶段扩展。
- 客户事实只接受白名单类型，非典型表达可能需要店主手动补充或澄清；
- 事实是商家业务记录，不作医疗诊断或安全结论；
- 产品本地名称特征是短文本消歧策略，不是正式 Embedding 服务，不保存向量；
- 新产品允许仅有名称并保持 `draft/incomplete`，品牌、规格和知识来源需后续补齐；
- 真实语音供应商仍未接入，经编辑的转写文本已走与手动输入相同的 Proposal 链路；
- 本地开发身份仍由服务端配置提供，正式登录和远程 HTTPS 属于后续远程阶段；
- 完整 AI 泛化评估和队列运行器属于后续评测阶段，本阶段不宣称实际模型泛化指标。

## 3. 明确未开始的内容

阶段5尚未开始。当前没有 ProductKnowledgeEntry、知识审核、知识版本、Chunk、EmbeddingRecord、向量库、RAG 检索、引用生成、断言支撑检查或知识回退协议。阶段6的推荐也未开始。

## 4. 当前停点

阶段4已完成并暂停，等待人工验收。本文不构成阶段5开发授权。
